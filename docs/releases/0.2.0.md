# Русификатор 0.2.0

Для **Football Coach: College Dynasty 1.6.5**, Steam build **19732424**, Windows.

Скачайте **FCCD-RU-0.2.0.zip**, распакуйте целиком, закройте игру и запустите `INSTALL.cmd`. Для возврата английской версии используйте `RESTORE.cmd`.

Переведены меню, состав, набор игроков, экран матча, новости, события, цели спонсоров и подсказки. Добавлены 4 987 словарных записей и 1 151 шаблон. Терминология проверена для американского футбола; названия команд, имена и принятые обозначения позиций сохранены.

Проверены шаблоны, 63 проверки форматов и терминов, составные новости за две недели, завершение матча и переход на следующую неделю на копии игры. Работают обновление с 0.1.0 и откат к оригиналу.

Полная игра и сохранения не включены. Совместимость с другими сборками не заявлена. Контрольная сумма ZIP приложена в `SHA256SUMS.txt`.

Подробнее: [установка и откат](../../README.md), [терминология](../TERMINOLOGY.md), [изменения](../../CHANGELOG.md).
